# Data Analysis & Machine Learning Portfolio

A collection of my projects in data analysis, natural language processing, and machine learning. Each project is a self-contained Jupyter notebook with its data, code, and write-up.

## Repository Structure

```
Portfolio/
├── Data_Analysis_Projects/   # Exploratory analysis, statistics, and HR analytics
│   └── Academic_Projects/    # Analyses from academic research and coursework
├── NLP_Projects/             # Extracting structure and meaning from text
└── ML_Projects/              # Machine learning models and experiments (coming soon)
```

| Folder | Purpose |
|---|---|
| `Data_Analysis_Projects/` | Turning raw datasets into insights: cleaning, EDA, visualization, and statistical modeling. Includes HR analytics case studies and a movie-rating bias analysis. |
| `Data_Analysis_Projects/Academic_Projects/` | Data analysis carried out in an academic or research context. |
| `NLP_Projects/` | Text processing and information extraction, e.g. subject–predicate–object fact extraction with spaCy. |
| `ML_Projects/` | Predictive modeling and machine learning projects. New projects coming soon. |

## Tools

Python (Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, spaCy), Jupyter Notebooks.

## Usage

Open any notebook to see the full workflow, from data sources and methodology to results. Feel free to explore and adapt the code.

The portfolio is updated regularly, and feedback is welcome!
