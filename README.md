# Data Analysis and Machine Learning Portfolio

This repository showcases a collection of my projects in the field of data analysis. From exploring datasets to deriving meaningful insights, each project demonstrates my skills in handling data and extracting valuable information.

## Repository Structure

- **HR_Analytics_Projects/** — HR analytics case studies covering employee performance and organizational effectiveness.
- **NLP_Projects/** — Natural language processing projects focused on extracting structure and meaning from text.
- **ML_Projects/** — Machine learning and statistical analysis projects.

## Projects

### HR_Analytics_Projects

#### 1. Predicting Employee Performance
- **Objective:** Identify the profile of high-performing employees and predict whether an employee will meet key performance indicator (KPI) criteria.
- **Methodology:** Logistic regression classification on employee HR data (department, education, training history, tenure, previous ratings, etc.), evaluated with a confusion matrix and ROC/AUC analysis.
- **Tools:** Python (Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn), Jupyter Notebooks.

#### 2. Enhancing Organizational Effectiveness through HR Analytics
- **Objective:** Build a holistic view of an organization by analyzing demographics and management structure, performance, employee satisfaction, and counterproductive work behavior.
- **Methodology:** Exploratory data analysis and visualization across departments to surface relationships between performance scores, satisfaction, salary, and behavioral metrics (e.g., absences, lateness).
- **Tools:** Python (Pandas, NumPy, Matplotlib, Seaborn), Jupyter Notebooks.

### NLP_Projects

#### Project_FactExtractor: Fact-like Structure Extraction with SpaCy
- **Objective:** Extracts subject-predicate-object (SPO) structures from text corpus to reveal fact-like relationships.
- **Methodology:** Leverages SpaCy for accurate and context-aware text processing.
- **Key Features:** Focuses on fact-like structures, handles text corpora, and presents structured outputs.
- **Applications:** Enhances information retrieval, aids data analysis, and supports automated processing.
- **Tools:** Primarily utilizes SpaCy for linguistic analysis.

### ML_Projects

#### Project_RatingRealities: Movies Rating Bias Analysis
- **Objective:** Explored patterns and trends to check scoring bias in movie ratings.
- **Methodology:** Using visualizations to depict the bias and data analysis to determine the bias level.
- **Tools:** Python (Pandas, NumPy, Matplotlib, Seaborn), Jupyter Notebooks.
